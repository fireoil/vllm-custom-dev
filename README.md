# vLLM 架构分析教程 —— 原理 + 实操，知行合一

> **课程版本基线**：vLLM **v0.31.0**（2026-10-05 发布，撰写本教程时的最新稳定版）。
> vLLM 迭代很快，但 V1 架构的核心组件（调度器 / KV Cache 管理 / ModelRunner）自 2025 年起保持稳定，
> 学完本课程后即使版本更新，你也能通过"源码走读方法"（第 06 章）自行跟进。
>
> **演示硬件**：NVIDIA RTX 4060 Laptop 8GB —— 本课程所有实验都用**消费级小显存显卡**完成，
> 全部模型都是 0.5B~1.5B 的开源小模型，任何 6GB+ 显存的显卡（甚至部分纯 CPU 场景）都能跑。

---

## 三、"知行合一"是怎么设计的

每一章都遵循同一个节奏：

1. **原理** —— 用生活化类比 + 图示讲透机制（不看代码也能懂）
2. **源码** —— 指出该机制在 vLLM v0.31.0 源码中的真实位置（文件/类/方法）
3. **动手** —— 三档实验，量力而行：
   - 🔧 **零门槛**：`lab/` 目录下的**原理模拟器**（纯 Python，无 GPU 也能跑）
   - 🚀 **进阶**：真实 vLLM 实验（需要 GPU）
   - 🔬 **硬核**：给源码插桩/改参数观察行为变化

```
lab/
├── sim_paged_kv.py           # 🔧 模拟 PagedAttention 块管理（无GPU）
├── sim_continuous_batching.py# 🔧 模拟静态 vs 连续批处理（无GPU）
├── real_vllm_prefix_cache.py # 🚀 真机验证前缀缓存加速
├── real_vllm_bench.py        # 🚀 真机压测调度参数
├── first_run.py              # 🚀 第一个 vLLM 程序（第02章）
├── instrument.py             # 🔬 给引擎主循环插桩（第06章）
├── my_vllm_plugin/           # 🔬 完整可运行的 vLLM 插件包（第13章）
│   ├── pyproject.toml        #    3 个入口点组注册
│   └── my_vllm_plugin/       #    general / io_processor / endpoint 三类示例
└── tilelang/                 # 🔬 TileLang 算子渐进实验（第15章，需 CUDA+tilelang）
    ├── 01_gemm_tilelang.py           # GEMM：tile/流水/TensorCore
    ├── 02_rmsnorm_tilelang.py        # RMSNorm：带宽型优化
    └── 03_flash_attention_tilelang.py# 在线 softmax 全流程（压轴）
```

## 五、版本兼容性说明

本教程命令与源码路径基于 vLLM v0.31.x。快速确认你的版本：

```bash
python -c "import vllm; print(vllm.__version__)"
```

- v0.8+ 均为 V1 架构（本教程讲解的架构），章节内容基本适用；
- v0.31 中较新的特性（如 KV offload、hisparse）会在第 08 章标注"较新特性"；
- 若个别 API 签名变化，用 `python -c "help(...)"` 或官方文档对照即可，**核心思想十年内不会过时**。

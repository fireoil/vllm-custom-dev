01命令速查

命令速查（bash）
# ── 安装与验证 ────────────────────────────────
pip install -U vllm                          # 安装最新版(基线 v0.31.0)
python -c "import vllm; print(vllm.__version__)"
python -c "import vllm,os;print(os.path.dirname(vllm.__file__))"   # 源码位置

# ── 启动服务 ─────────────────────────────────
vllm serve <模型> --max-model-len 2048 --gpu-memory-utilization 0.85
vllm serve <模型> --tensor-parallel-size 2          # 2卡TP
vllm serve <模型> --quantization fp8                # 在线量化
vllm serve <模型> --kv-cache-dtype fp8              # KV量化
vllm serve <模型> --speculative-config '{"method":"ngram","num_speculative_tokens":5}'
vllm serve <模型> --enable-lora --lora-modules a=/path/a

# ── 压测 ────────────────────────────────────
vllm bench serve --backend vllm --model <模型> --num-prompts 200 --request-rate 10

# ── 观测 ────────────────────────────────────
curl localhost:8000/health                          # 健康检查
curl localhost:8000/metrics | grep -E "num_requests_(running|waiting)"
tail -f serve.log | grep -iE "preempt|blocks|Prefix"

02参数速查（最常用 12 个）

参数默认一句话说明
--model必填HF 模型名或本地路径
--max-model-len模型上限单请求最大上下文。吃 KV 座位的大户，按需设
--gpu-memory-utilization0.9可用显存比例。独占机器可 0.9+
--max-num-seqs1024并发请求数上限
--max-num-batched-tokens8192每步 token 预算（chunked prefill 也用它）
--tensor-parallel-size1TP 卡数（需整除头数/FFN 维度）
--pipeline-parallel-size1PP 级数（跨机用）
--enable-prefix-cachingV1 默认开前缀缓存
--dtypeautohalf/bfloat16/float16
--quantizationNonefp8/awq/gptq/bitsandbytes
--kv-cache-dtypeautoKV 量化（fp8 让座位翻倍）
--block-size16每块 token 数（一般不动）

04常见报错对照

报错关键词原因 → 解法详见
out of memory (启动)显存预算超了 → 降 utilization / max-model-len / 量化第09章 D
Found no NVIDIA driver驱动问题 → 宿主机装驱动, nvidia-smi 验证第02章
...heads is not divisible by tensor parallel sizeTP 整除约束 → 换 TP 值第07章
max seq len is larger than the maximum number of tokens...KV 座位装不下 → 减 max-model-len第04章
Preempted ... RECOMPUTE 刷屏抢占风暴 → 降并发/量化 KV第05章
输出乱码/缺字增量反分词拼接问题 → 检查客户端拼 delta 方式第06章
TTFT 突然变高前缀缓存失效(模板改了) / 超长请求插队第08/09章

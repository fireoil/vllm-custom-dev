## A. 命令速查

```bash
# ── 安装与验证 ────────────────────────────────
pip install -U vllm                          # 安装最新版(基线 v0.31.0)
python -c "import vllm; print(vllm.__version__)"
python -c "import vllm,os;print(os.path.dirname(vllm.__file__))"   # 源码位置

# ── 启动服务 ─────────────────────────────────
vllm serve <模型> --max-model-len 2048 --gpu-memory-utilization 0.85
vllm serve <模型> --tensor-parallel-size 2          # 2卡TP
vllm serve <模型> --quantization fp8                # 在线量化
vllm serve <模型> --kv-cache-dtype fp8              # KV量化
vllm serve <模型> --speculative-config '{"method":"ngram","num_speculative_tokens":5}'
vllm serve <模型> --enable-lora --lora-modules a=/path/a

# ── 压测 ────────────────────────────────────
vllm bench serve --backend vllm --model <模型> --num-prompts 200 --request-rate 10

# ── 观测 ────────────────────────────────────
curl localhost:8000/health                          # 健康检查
curl localhost:8000/metrics | grep -E "num_requests_(running|waiting)"
tail -f serve.log | grep -iE "preempt|blocks|Prefix"
```

## B. 参数速查（最常用 12 个）

| 参数 | 默认 | 一句话说明 |
|---|---|---|
| `--model` | 必填 | HF 模型名或本地路径 |
| `--max-model-len` | 模型上限 | 单请求最大上下文。**吃 KV 座位的大户，按需设** |
| `--gpu-memory-utilization` | 0.9 | 可用显存比例。独占机器可 0.9+ |
| `--max-num-seqs` | 1024 | 并发请求数上限 |
| `--max-num-batched-tokens` | 8192 | 每步 token 预算（chunked prefill 也用它） |
| `--tensor-parallel-size` | 1 | TP 卡数（需整除头数/FFN 维度） |
| `--pipeline-parallel-size` | 1 | PP 级数（跨机用） |
| `--enable-prefix-caching` | V1 默认开 | 前缀缓存 |
| `--dtype` | auto | half/bfloat16/float16 |
| `--quantization` | None | fp8/awq/gptq/bitsandbytes |
| `--kv-cache-dtype` | auto | KV 量化（fp8 让座位翻倍） |
| `--block-size` | 16 | 每块 token 数（一般不动） |

## C. 术语表

## D. 常见报错对照

| 报错关键词 | 原因 → 解法 | 详见 |
|---|---|---|
| `out of memory` (启动) | 显存预算超了 → 降 utilization / max-model-len / 量化 | 第09章 D |
| `Found no NVIDIA driver` | 驱动问题 → 宿主机装驱动, nvidia-smi 验证 | 第02章 |
| `...heads is not divisible by tensor parallel size` | TP 整除约束 → 换 TP 值 | 第07章 |
| `max seq len is larger than the maximum number of tokens...` | KV 座位装不下 → 减 max-model-len | 第04章 |
| `Preempted ... RECOMPUTE` 刷屏 | 抢占风暴 → 降并发/量化 KV | 第05章 |
| 输出乱码/缺字 | 增量反分词拼接问题 → 检查客户端拼 delta 方式 | 第06章 |
| TTFT 突然变高 | 前缀缓存失效(模板改了) / 超长请求插队 | 第08/09章 |
